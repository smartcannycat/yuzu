# Vue 3 SPA Template

Minimalist starter template for Vue 3 Single Page Applications.

## Tech Stack

Vue 3, TypeScript, Vite, Tailwind CSS v4, Vue Router, Pinia, Vue DevTools, oxlint, oxfmt, Lefthook, Bun.

## Quick Start

```bash
bun install
bun run dev
```

## Scripts

- `bun run dev` - Start dev server
- `bun run build` - Typecheck and build for production
- `bun run preview` - Preview production build
- `bun run typecheck` - Run vue-tsc
- `bun run lint` - Run oxlint
- `bun run lint:fix` - Fix oxlint issues
- `bun run format` - Format code with oxfmt
- `bun run format:check` - Check formatting with oxfmt
