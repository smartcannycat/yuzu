## 1. Стартовые ресурсы и окружение (Фаза 0)

- [ ] **Эталонная пара аукционных листов для демонстрации арбитража:**
  - Математический эталон зафиксирован в [BENCHMARK_CASE_COROLLA_TOURING.md](../docs/BENCHMARK_CASE_COROLLA_TOURING.md) (`Toyota Corolla Touring`, `Frame ID: NRE210-2005418`, TAA Chubu #3142 оценка `3.5` vs USS Tokyo #80215 завышенная оценка `4.0`).
  - Разместить исходные изображения обоих листов + тестовое фото с iPhone (`.heic`/`.jpg`) в каталоге тестовых ассетов для прогона ML-пайплайна и прогрева эталонного кэша.

- [ ] **API-ключи и внешние шлюзы:**
  - [ ] Подготовлен пул из 3 проверенных API-ключей Multimodal Vision LLM (Gemini) с учётом лимитов `5 RPM` и резервных fallback-сценариев.
  - [ ] Проверен доступ к шлюзу котировок ЦБ РФ (`https://www.cbr-xml-daily.ru/daily_json.js`) и донорам (Drom, Farpost, AucJP / AAA Japan / Pravto) с настроенными резервными fallback-значениями.

- [ ] **Инициализация репозиториев и окружения (`Шлюз 1`):**
  - [ ] Модуль `ml/`: отдельный микросервис `FastAPI` + `Pydantic` + `pillow-heif` + `Uvicorn` (`/internal/parse/*`).
  - [ ] Модуль `backend/`: `Django Ninja` + JWT Auth + асинхронный воркер очереди + Read-Through кэш.
  - [ ] Модуль `frontend/`: адаптивное веб-приложение (стек на выбор фронтендера), токены из [DESIGN.md](../docs/DESIGN.md), `Lucide Icons` и локальный Mock Service (`MockApiClient` / `MSW`).

## 2. Контрольные точки проектирования и архитектуры (Фаза 0 — закрыто до старта кода)

- [ ] **Выбор финального названия бренда:** быстрое голосование команды по шорт-листу из [03_PRODUCT_NOMENCLATURE_ANALYSIS.md](./03_PRODUCT_NOMENCLATURE_ANALYSIS.md) (рабочее название — `AuctionCalc`).
- [x] **Архитектурный периметр и микросервисы:** Клиентские интерфейсы взаимодействуют исключительно с Backend API (`Django Ninja`) по REST; Backend оркестрирует отдельный ML-микросервис (`FastAPI`) через `/internal/parse/*`. Прямые клиентские вызовы ML исключены.
- [x] **Контракты данных и сущности:** Зафиксированы 40 Pydantic-схем и 7 провалидированных JSON-фикстур в [API_DATA_CONTRACTS.md](../docs/API_DATA_CONTRACTS.md) (`FastHeaderPreview`, `ParserResponse`, 16 зон 2D-схемы `BodyPanel`, 13 флагов `RiskFlags`, Drom/Farpost-блоки, RFC 7807 ошибки).
- [x] **Авторизация и автономная разработка фронта:** Утверждены JWT Auth (`/auth/register`, `login`, `refresh`, `me`), авто-сидинг 3 стартовых лотов каждому новому пользователю и локальный Mock Service на стороне Frontend (`FE-01`) вместо временных HTTP-заглушек на бэкенде.
- [x] **Нормативные финансовые параметры и математика сметы:** Зафиксированы и сведены до рубля в [BENCHMARK_CASE_COROLLA_TOURING.md](../docs/BENCHMARK_CASE_COROLLA_TOURING.md) и `API_DATA_CONTRACTS.md` (пошлина ЕАЭС 3–5 лет, льготный утильсбор `5 200 ₽` при мощности `<= 160` л.с. vs коммерческая сетка `> 160` л.с., FOB + фрахт + расходы Владивостока + Farpost-ремонт).
- [x] **Дизайн-система, прототипы и бэклог:** Готовы вайрфреймы всех 6 экранов в [assets/wireframes_and_flows.png](../docs/assets/wireframes_and_flows.png), токены в [DESIGN.md](../docs/DESIGN.md), скоп клиентского печатного `[PDF]` в MVP (`P0`, серверный `report.pdf` перенесён в `P1`) и 3-трековый бэклог в [05_TEAM_BACKLOG.md](./05_TEAM_BACKLOG.md).

## 3. Финальная валидация демонстрационного стенда (перед код-фризом)

- [ ] **Отказоустойчивый кэш:** Проверена отдача эталонного кейса `Corolla Touring NRE210-2005418` и запасных кэшей Drom/Farpost/AucJP без сбоев при деградации внешних сайтов.
- [ ] **Адаптивный веб-клиент и загрузка с телефона:** Проверка загрузки фото аукционника с мобильного браузера (включая `.heic` / `.jpg`), отображения миниатюры `sheet_thumb.webp`, прогресса `FastHeaderPreview` и работы 2D-схемы на узком экране.
- [ ] **JWT и единый аккаунт:** Проверка регистрации/входа с любых устройств под одним аккаунтом, мгновенного появления 3 демо-лотов и сохранения истории расчётов.
- [ ] **Сквозной интеграционный прогон:** Регистрация → Загрузка фото → Быстрый заголовок → Табы 4/5/6 + `recalculate` слайдеры → Печатный `[PDF]` без ошибок в консоли и сети.
- [ ] **Резервная видеозапись:** Наличие Full HD скринкаста работы системы на случай технических сбоев презентационного оборудования.
